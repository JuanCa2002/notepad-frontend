# 🗒️ My Notepad (Frontend) <a name="title-and-description"></a>

My Notepad is an intuitive note-taking application that allows users to organize their ideas, tasks, and information efficiently. The frontend is developed using **Angular**.

## ✨ Features <a name="features"></a>

- **Login**: Authenticate users to access their personal notes.
- **Profile**: Manage user information and settings.
- **Category and Note Management**: Organize notes into categories (tags) and manage them effectively.

## 🔧 Installation <a name="installation"></a>

To run the project locally, follow these steps:

1. **Clone the repository**:

   ```
   git clone https://github.com/hirelens-challenges/TorresBeltran-97eb43.git
   ```
2. **Navigate to the project directory:**
     ```
    cd my-notepad/
    cd frontend/
    cd notepad-frontend/
   ```
3. **Install the dependencies:**
   ```
   npm install
   ```
4. **Start the development server:**
   ```
   ng serve
   ```
